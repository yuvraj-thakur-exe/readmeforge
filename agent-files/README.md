# Agent Files, Personalization Architecture & Milestone Tracking

This directory maintains agent memory, autonomous execution plans, architectural specifications, and development history separated from the core ReadmeForge application code.

## Directory Overview

- **`memory.md`**: Authoritative system memory, architectural invariants, verified external endpoints, and milestone history.
- **`REBRAND_CHECKLIST.md`**: Complete rebrand checklist and verification records.
- **`plans/`**: Detailed technical execution plans, including the comprehensive 2026-10-25 ReadmeForge architectural roadmap.
- **`devin/`**: Autonomous workspace rules, lint requirements, and defensive engineering invariants.

## Key Architectures Documented

### 1. Domain-Tailored Personalization Engine (`src/lib/personalization/`)
- Generates distinct, personalized GitHub profile configurations across 5 key engineering roles:
  - **AI / Machine Learning Researcher** (latent diffusion, multi-agent frameworks, PyTorch/CUDA).
  - **Platform & Cloud SRE Architect** (zero-trust meshes, Kubernetes, Terraform, GitOps).
  - **Senior Full-Stack Polyglot** (distributed systems, Next.js 16, serverless edge, Postgres).
  - **Creative & UI/UX Motion Specialist** (Three.js shaders, WebGL, 60fps springs, spatial design).
  - **Systems & Low-Level Embedded Engineer** (Rust, modern C++, bare-metal firmware, lock-free concurrency).
- Guarantees that profiles are not generic or identical: assigns domain-custom typing SVGs, specific Shields.io badge matrices, custom bio bullets, and harmonized color palettes.

### 2. Interactive Charts & Graphs Suite (`src/lib/plugins/wrappers/`)
- **`activity-graph`**: Annual commit velocity line graphs and density heatmaps powered by high-availability endpoints (`ghchart.rshah.org`).
- **`pie-chart`**: Top languages donut/pie visualizers (`layout=donut`, `layout=pie`) and native Mermaid Markdown pie charts (`pie title ...`) with zero external image dependencies.
- **`github-readme-stats`**: Live stars, commits, PR counts, and language ranking cards.
- **`snk`**: Automated contribution grid eating snake animations.

### 3. Pure Vector Motion & SVG Animation Suite
- In-browser **Animation Studio** (`/animator`) and AI skill (`.agents/skills/readme-animation-studio/SKILL.md`).
- Real-time CSS `@keyframes` animations, cyber neon frames, CRT scanlines, fire heatwaves, caustic water ripples, and customizable animated character sprites.

## ⚡ Quick Start

### 1. Web Studio &amp; Metrics Studio
- **Profile Studio**: Open [`/wizard`](file:///d:/profile%20genrater/src/app/[locale]/wizard) for interactive layout building.
- **Metrics Studio**: Open [`/metrics`](file:///d:/profile%20genrater/src/app/[locale]/metrics) to configure and live-preview all 47+ plugins.
- **Developer IDE**: Open [`/developer`](file:///d:/profile%20genrater/src/app/[locale]/developer) for split-screen Monaco Markdown editing.

### 2. Instant CLI Generation (Zero Installation)
```bash
# Generate high-impact 3D City Cat profile
npx readmeforge generate --username <your-username> --archetype wow-3d-city-cat --output README.md

# Generate Bento Signal Dashboard
npx readmeforge generate --username <your-username> --archetype bento-signal-dashboard --output README.md

# List all available archetypes in your terminal
npx readmeforge list
```

### 3. Run Locally (Node.js 20+ &amp; pnpm)
```bash
# 1. Clone the repository
git clone https://github.com/yuvraj-thakur-exe/readmeforge.git
cd readmeforge

# 2. Install dependencies
pnpm install

# 3. Start dev server
pnpm dev
# Web Studio runs on http://localhost:3000

# 4. Start standalone Metrics server
pnpm metrics:start
```

## 📊 ReadmeForge Metrics (47+ Plugins)

**ReadmeForge** integrates a comprehensive, standalone infographics &amp; telemetry engine with **47+ plugins** and **335+ options**.

### Turnkey GitHub Actions Workflow

Create `.github/workflows/readmeforge-metrics.yml` in your profile repository (`<username>/<username>`):

```yaml
name: ReadmeForge Metrics
on:
  schedule:
    # Runs daily at midnight UTC
    - cron: "0 0 * * *"
  workflow_dispatch:
  push:
    branches: [master, main]

jobs:
  readmeforge-metrics:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - name: Checkout Repository
        uses: actions/checkout@v4

      - name: Generate ReadmeForge Metrics
        uses: lowlighter/metrics@latest
        with:
          filename: github-metrics.svg
          token: ${{ secrets.METRICS_TOKEN }}
          user: ${{ github.repository_owner }}
          template: classic
          config_timezone: UTC
          base: header, activity, community, repositories, metadata
          plugin_isocalendar: yes
          plugin_isocalendar_duration: half-year
          plugin_languages: yes
          plugin_languages_limit: 8
          plugin_habits: yes
          plugin_habits_from: 200
          plugin_habits_days: 14
          plugin_achievements: yes
          plugin_achievements_threshold: B
```

Then embed into your profile:
```markdown
<div align="center">
  <img src="github-metrics.svg" alt="Metrics Telemetry" />
</div>
```

## 🧩 Plugin Encyclopedia &amp; Capabilities

### 1. 📅 3D Isometric Commit Calendar
Visualizes your commit history as an axonometric 3D projection:
- **Options**:
  - `plugin_isocalendar: yes`
  - `plugin_isocalendar_duration: half-year` (180 days) or `full-year` (365 days)
- **Output**: Detailed voxel-style commit peaks rendering activity intensity.

### 2. 🈷️ Languages Activity &amp; Deep Inspection
Displays your most frequently used programming languages across repositories:
- **Options**:
  - `plugin_languages: yes`
  - `plugin_languages_limit: 8` (number of languages to display)
  - `plugin_languages_ignored: html, css, tex` (exclude languages)
  - `plugin_languages_sections: most-used, recently-used`
  - `plugin_languages_details: bytes, percentage, lines`
  - `plugin_languages_indepth: yes` (clones repositories for byte-level accuracy)
  - `plugin_languages_colors: "typescript:#3178c6, rust:#dea584"`

### 3. ⏱️ Coding Habits, Active Hours &amp; Rhythms
Analyzes your commit schedules, preferred development hours, and peak productive days:
- **Options**:
  - `plugin_habits: yes`
  - `plugin_habits_from: 200` (number of events to analyze)
  - `plugin_habits_days: 14` (day analysis window)
  - `plugin_habits_facts: yes` (displays productivity facts &amp; rhythm stats)
  - `plugin_habits_charts: yes` (renders 24-hour circular or linear rhythm charts)

### 4. 🏆 Gamified GitHub Achievements
Awards badges and medals based on historical commit achievements, pull requests, and repository milestones:
- **Options**:
  - `plugin_achievements: yes`
  - `plugin_achievements_threshold: B` (rank filters: `C`, `B`, `A`, `S`, `X`)
  - `plugin_achievements_secrets: yes` (unlock hidden Easter-egg trophies)
  - `plugin_achievements_display: compact` or `detailed`
  - `plugin_achievements_limit: 10`

### 5. 🗳️ LeetCode Statistics
Renders LeetCode competitive programming progress:
- **Options**:
  - `plugin_leetcode: yes`
  - `plugin_leetcode_user: <username>`
  - `plugin_leetcode_sections: solved, skills, recent`

### 6. ⏰ WakaTime Productivity Breakdown
Renders verified coding time tracked across languages, projects, and code editors:
- **Options**:
  - `plugin_wakatime: yes`
  - `plugin_wakatime_token: ${{ secrets.WAKATIME_TOKEN }}`
  - `plugin_wakatime_days: 7`
  - `plugin_wakatime_sections: time, projects, languages, editors`

### 7. ✨ Stargazers Growth &amp; World Map
Visualizes your repository star growth curves and worldwide geographic stargazer distribution:
- **Options**:
  - `plugin_stargazers: yes`
  - `plugin_stargazers_charts: yes`
  - `plugin_stargazers_worldmap: yes`

### 8. 👨‍💻 Lines of Code Changed
Tracks cumulative lines of code added, modified, and deleted across all contributions:
- **Options**:
  - `plugin_lines: yes`
  - `plugin_lines_history: yes` (renders historical diff trend graph)

### 9. 📌 Starred Topics &amp; Mastered Tech
Renders technology badges for topics you actively star and contribute to:
- **Options**:
  - `plugin_topics: yes`
  - `plugin_topics_mode: starred` or `mastered`
  - `plugin_topics_sort: stars` or `activity`
  - `plugin_topics_limit: 15`

### 10. 🎼 Music &amp; Spotify Activity
Live-updates with your currently playing or recently played music and favorite playlists:
- **Options**:
  - `plugin_music: yes`
  - `plugin_music_provider: spotify` or `apple`
  - `plugin_music_mode: recent` or `playlist`

### 11. 🎩 Notable Contributions &amp; Sponsorships
Showcases significant contributions made to major open-source repositories and verified GitHub Sponsors:
- **Options**:
  - `plugin_notable: yes`
  - `plugin_notable_indepth: yes`
  - `plugin_sponsors: yes`
  - `plugin_sponsorships: yes`

### 12. 💬 Discussions, Issues &amp; Follow-up
Surfaces GitHub Discussions participation, open pull requests, and review requests:
- **Options**:
  - `plugin_discussions: yes`
  - `plugin_followup: yes`
  - `plugin_followup_indepth: yes`

### 13. ⏱️ Google PageSpeed Insights &amp; Web Telemetry
Audits your portfolio or project URL for Performance, Accessibility, Best Practices, and SEO:
- **Options**:
  - `plugin_pagespeed: yes`
  - `plugin_pagespeed_url: https://your-portfolio.dev`
  - `plugin_pagespeed_detailed: yes`

### 14. 🕹️ Steam &amp; Chess Gaming Activity
Highlights verified gaming achievements and ratings:
- **Options**:
  - `plugin_steam: yes`
  - `plugin_community_chess: yes`

## 🤖 AI Agent Skill &amp; MCP Server

ReadmeForge is designed for autonomous AI Agents (Claude Code, Cursor, Devin, Antigravity, GitHub Copilot).

### 1. Install as an Agent Skill (1-Liner)
```bash
# macOS / Linux / WSL
curl -fsSL ./scripts/install-agent-skill.sh | bash

# Windows PowerShell
irm ./scripts/install-agent-skill.ps1 | iex

# Or via CLI
npx readmeforge skill-install
```

### 2. Connect as a Model Context Protocol (MCP) Server
Add to your Cursor (`.cursor/mcp.json`) or Claude Desktop configuration:

```json
{
  "mcpServers": {
    "readmeforge": {
      "command": "npx",
      "args": ["readmeforge", "mcp"]
    }
  }
}
```

## 🔒 Security &amp; Open Source Invariants

- **100% Free &amp; Open Source**: Zero restrictions, zero corporate gatekeeping. All discussions, security proposals, and enhancements take place transparently in public GitHub Issues and Pull Requests.
- **Local-First Privacy**: Personal Access Tokens and session configs live exclusively in ephemeral browser memory and are **never** transmitted to remote databases or telemetry servers.
- **Scoped Permissions**: Actions workflows need only fine-grained permissions for `<username>/<username>`.
- **Confirmation Gates**: ReadmeForge never pushes silently to GitHub — users review side-by-side diff previews and explicitly confirm pushes.

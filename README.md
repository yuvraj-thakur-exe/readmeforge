## ⚡ Quick Start

### 1. Interactive Web Studio
- **Profile Studio Wizard**: Launch [`/wizard`](https://monoforge-studio.vercel.app/en/wizard) for visual drag-and-drop authoring.
- **Developer Raw Mode**: Open [`/developer`](https://monoforge-studio.vercel.app/en/developer) for real-time Monaco JSON editing with integrated Cyber Monkey Co-Pilot.
- **Telemetry Arsenal**: Access [`/telemetry`](https://monoforge-studio.vercel.app/en/telemetry) to explore all 47+ telemetry engines.
- **Vector Animator**: Visit [`/animator`](https://monoforge-studio.vercel.app/en/animator) for custom animated vector banners and kinetic typography.

### 2. Standalone GitHub Actions Workflow (Zero External Dependencies)

Create `.github/workflows/monoforge-telemetry.yml` in your profile repository:

```yaml
name: MonoForge Telemetry Sync

on:
  schedule: [{cron: "0 0 * * *"}] # Daily at midnight UTC
  workflow_dispatch:
  push: {branches: ["master", "main"]}

jobs:
  telemetry-sync:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: actions/checkout@v4
      - name: Generate MonoForge Telemetry
        uses: yuvraj-thakur-exe/MONOFORGE@main
        with:
          token: ${{ secrets.TELEMETRY_TOKEN }}
          user: ${{ github.repository_owner }}
          template: classic
          base: header, activity, community, repositories, metadata
          plugin_isocalendar: yes
          plugin_isocalendar_duration: full-year
          plugin_languages: yes
          plugin_languages_details: bytes-size, percentage
          plugin_habits: yes
          plugin_habits_from: 200
          plugin_habits_charts: yes
          plugin_achievements: yes
          plugin_achievements_display: detailed
          plugin_leetcode: yes
          plugin_leetcode_user: ${{ github.repository_owner }}
```

## 💻 Developer Mode (`/developer`)

For power users who prefer raw code over drag-and-drop:

- **Monaco JSON Editor**: Full bidirectional sync with the single Zustand store. Syntax validation via strict Zod schema.
- **Embedded Cyber Monkey Co-Pilot**: Interactive assistant providing real-time AST tips, schema error diagnostic messages, and 1-click plugin injection.
- **Multi-Device Live Preview**: Toggle between Desktop, Cyber CRT Terminal (with scanlines), and Mobile iPhone viewpoints.
- **Design Token Switcher**: Live badge style selection (`for-the-badge`, `flat`, `flat-square`) and alignment controls.
- **Confirmation-Gated GitHub Sync**: Push directly to your repository with live diff review and mandatory explicit approval.

## 🛠️ Setup & Local Development

### Prerequisites
- Node.js 18.17+ or 20+
- pnpm 9+ (`corepack enable && corepack prepare pnpm@latest --activate`)

```bash
# 1. Clone repository
git clone https://github.com/yuvraj-thakur-exe/MONOFORGE.git
cd MONOFORGE

# 2. Install dependencies
pnpm install

# 3. Start local development server with Turbopack
pnpm dev

# 4. Open in browser
# Local Studio: http://localhost:3000
# Developer IDE: http://localhost:3000/en/developer
# Telemetry Studio: http://localhost:3000/en/telemetry
```

### Verification & Testing
```bash
# Run unit & integration tests
pnpm test

# Run TypeScript type check
pnpm type-check

# Run linter
pnpm lint

# Production build
pnpm build
```

## 🔒 Security & Architecture Invariants

1. **Confirmation Gate Guarantee**: Zero writes occur to your GitHub repository without explicit review and approval in the diff modal.
2. **Pure Markdown Generation**: `buildMarkdown(config)` is a side-effect-free pure function tested under 100% test coverage.
3. **Camo Resilient**: All SVGs use standard CSS `@keyframes` with zero inline JavaScript, preventing GitHub Camo proxy breakage.
4. **Single Source of Truth**: Unified Zustand store (`src/store/useReadmeStore.ts`) ensures the visual wizard and `/developer` raw mode never drift out of sync.
